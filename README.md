### SortView AMH Analytics Platform

**Python · FastAPI · PostgreSQL · Streamlit · Alembic · Data Pipelines**

[Live Application](https://sortview.streamlit.app/) · [GitHub Profile](https://github.com/richardrhanly-us)

SortView is a multi-part analytics system for Automated Materials Handler activity in a public-library environment. It collects machine-generated log data, stores structured records in PostgreSQL, and presents operational dashboards, reports, transit analysis, and troubleshooting information.

**What I built**

- Developed a Windows-side agent that reads local sorter logs and uploads data automatically.
- Built a FastAPI backend that receives uploads and writes normalized records to Neon PostgreSQL.
- Created a Streamlit dashboard for live monitoring, historical reports, routing analysis, alerts, and operational troubleshooting.
- Added authentication, organization and branch access controls, database migrations, configurable settings, and automated tests.
- Designed the system around a real operational workflow rather than a sample dataset.

**Why it matters**

SortView demonstrates end-to-end system design: data ingestion, API development, database modeling, analytics, deployment, user feedback, and ongoing maintenance.

### Aircraft Mission Systems Simulator

**C++17 · CMake · CTest · UDP · Winsock · JSON · Automated Testing**

[Source Code](https://github.com/richardrhanly-us/aircraft-mission-simulator)

A distributed C++ simulator that models communication between aircraft telemetry, mission-control, and command-processing subsystems.

**What I built**

- Created separate C++ processes that communicate through UDP sockets.
- Implemented JSON serialization and deserialization for telemetry, commands, and responses.
- Added validation for aircraft data, command values, message fields, and schema versions.
- Detects missing, duplicate, out-of-order, stale, recovered, and restarted telemetry streams.
- Added controllable packet-loss simulation for fault testing.
- Implemented command acknowledgment and rejection messaging for heading, altitude, status, and return-to-base commands.
- Built automated CTest suites for validation, health monitoring, malformed messages, serialization, and command handling.
- Added architecture, protocol, test-plan documentation, and demonstration screenshots.

**Why it matters**

This project demonstrates systems programming, inter-process communication, subsystem interfaces, fault detection, defensive programming, and verification-oriented software development.
