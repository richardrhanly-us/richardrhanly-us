### SortView AMH Analytics Platform

**Python · FastAPI · PostgreSQL · Streamlit · Alembic · Data Pipelines**

[Live Application](https://sortview.streamlit.app/) ·
[Source Code](https://github.com/richardrhanly-us/amh-analytics-dashboard)

SortView is a production-oriented analytics platform for Automated Materials Handler activity in a public-library environment. It collects machine-generated log data, stores normalized records in PostgreSQL, and provides dashboards, operational reports, transit analysis, alerts, and troubleshooting tools.

**Highlights**

- Built a Windows-side agent that automatically reads and uploads sorter logs.
- Developed a FastAPI backend for validating and storing incoming records.
- Created a Streamlit dashboard for live monitoring and historical analysis.
- Added authentication, organization and branch access controls, database migrations, configuration management, and automated tests.
- Designed the system around an active real-world operational workflow rather than a sample dataset.

**Demonstrates:** end-to-end system design, backend development, data ingestion, database modeling, analytics, deployment, testing, and maintenance.

### Aircraft Mission Systems Simulator

**C++17 · CMake · CTest · UDP · Winsock · JSON · Automated Testing**

[Source Code](https://github.com/richardrhanly-us/aircraft-mission-simulator)

A distributed C++ simulator that models communication between aircraft telemetry, mission-control, and command-processing subsystems.

**Highlights**

- Created independent C++ processes that communicate through UDP sockets.
- Implemented JSON serialization for telemetry, commands, acknowledgments, and error responses.
- Detects missing, duplicate, out-of-order, stale, recovered, and restarted telemetry streams.
- Added controllable packet-loss simulation for fault testing.
- Implemented validation for data values, message fields, command inputs, and protocol versions.
- Built automated CTest suites covering validation, health monitoring, malformed messages, serialization, and command handling.
- Documented the architecture, communication protocol, test plan, and demonstration scenarios.

**Demonstrates:** systems programming, inter-process communication, fault detection, defensive programming, protocol design, and software verification.
